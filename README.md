# Prism Path

A 3D laser-routing puzzle that runs in the browser (Three.js, no build step).

Turn the mirrors so light from the emitter reaches the glowing receptor.

## Run it
1. Unzip the folder.
2. Open a terminal in the folder (Windows Command Prompt) and start a local server:
   python -m http.server 8000
3. Open http://localhost:8000 in Chrome or Edge.

Three.js and the fonts load from CDNs, so you need an internet connection.

## Files
- index.html: layout, menu, HUD and result screens
- style.css: design tokens and component styles
- puzzle.js: level generator, beam tracing, difficulty curve (no DOM)
- audio.js: all sound effects and ambient music, synthesized with Web Audio
- main.js: 3D scene, shadows, bloom, input and game flow

## Modes
- Campaign: 12 levels. Boards grow, decoy mirrors and walls appear. Stars reward the fewest moves (par).
- Hard Mode: 6 larger levels with locked mirrors, a countdown timer and a move limit (minimum moves + 1).

Every level is generated by carving a real light route first, so each puzzle is always solvable.

## Controls
- Click a mirror to flip it between / and \.
- Drag to orbit the camera, scroll or pinch to zoom.
- Top bar: mute, restart level, main menu.
